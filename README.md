# Character Vault · Web app

Web app per smartphone di **Character Vault** (la stessa interfaccia inclusa nell'app Android): galleria,
ricerca, personaggi, catalogo e aggiunta di immagini, letti dall'archivio su Google Drive con il proprio account.

- Si apre da `https://turiddus.github.io/character-vault-web/` e si installa con «Aggiungi a schermata Home».
- Nessun dato né chiave in questo repository: l'ID client OAuth si inserisce al primo accesso e resta nel telefono.
- L'archivio viene pubblicato su Drive dal programma Character Vault sul PC (versione 7.1).
- Le foto caricate arrivano sempre come originali; le schede già importate non compaiono più tra quelle in attesa.
