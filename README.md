# Character Vault · Web app

Web app per smartphone di **Character Vault**: galleria, ricerca, personaggi, catalogo e aggiunta di immagini,
letti dall'archivio su Google Drive con il proprio account Google.

- Si apre da `https://turiddus.github.io/character-vault-web/` e si installa con «Aggiungi a schermata Home».
- Nessun dato né chiave in questo repository: l'ID client OAuth si inserisce al primo accesso e resta nel telefono.
- L'archivio viene pubblicato su Drive dal programma Character Vault (4.3.0+) sul PC.
